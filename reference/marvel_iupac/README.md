# MARVEL/IUPAC benchmark targets

This folder stores a **small, curated subset** of MARVEL/IUPAC vibrational band origins used as “truth” targets for
validating **high stretch overtones / stretch–stretch combination bands** in real water monomers.

- Targets live in `reference/marvel_iupac/vbo_stretch_targets.json`.
- Provenance is recorded per entry (DOI + table id).

These files are **benchmark reference data** and should be edited only with care (and with citations updated in
`docs/benchmarks.md`).
